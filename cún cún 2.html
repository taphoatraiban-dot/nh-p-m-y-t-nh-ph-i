📖 BẢNG HƯỚNG DẪN NHẬP PHƠI

* Cách viết tên đài

Viết tắt chữ cái đầu: bến tre → bt, vũng tàu → vt.
Tên đài trùng chữ cái đầu thì viết rõ hơn: dnang, dnong.

* Các loại tên đài

2 đài miền Nam: 2dmn → 3, 4 đài: 3dmn, 4dmn.
2 đài miền Trung: 2dmt → 3 đài: 3dmt.
2 đài bất kỳ: vl.tv.

* Cách viết kiểu đánh

Đầu đuôi: dd → 12dd10.
Xỉu chủ: xc, x → 123xc10 hoặc 123x10.
Đầu/đuôi: 11dau10, 333dau10, 11duoi10, 333duoi10.
Bao lô: b → 12b10.
Đảo bao lô: daob, bdao → 123daob10.
Bao lô 7, 8: baobay, b7l, b8l → 33b7l50.
Bao lô 7, 8 đảo: b7ld, b7ldao → 123b7ld50.

* Đá

da, dv → 12.34da10 hoặc 12.34dv10.
Gộp nhiều cặp đá: 1234.4567da1.
Gộp nhiều kiểu cùng số: 66.88da1.b5.

* Đảo xỉu chủ

daoxc, dxc, xcdao → 123dxc10.
Đảo XC đầu: daodau, ddau → 123ddau10.
Đảo XC đuôi: daoduoi, daodui, dduoi, ddui.

* Nhất To — Xiên miền Bắc

Nhất To: nto, nhatto → 12nto10.
Xiên miền Bắc: xien → 12.34xien10.

* 12 Con Giáp

12giap, 12congiap → 12giap.dd10n.

* Tài — Xỉu — Chẵn — Lẻ

Tài: tai → taidd10n.
Xỉu: xiu → xiudd10n.
Chẵn: chan → chandd10n.
Lẻ: le → ledd10n.
Chẵn Chẵn: chanchan → chanchandd10n.
Lẻ Lẻ: lele → leledd10n.
Chẵn Lẻ: chanle → chanledd10n.
Lẻ Chẵn: lechan → lechandd10n.

* Kéo

20/30keo90duoi10n → 20, 30, 40...90.
60/61keo69dau15n → 60, 61, 62...69.
111/222keo999xc20n.
